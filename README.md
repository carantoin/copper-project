# Курсовая работа по Веб-программированию: COPPER PRO (Вариант №3)

Данный проект представляет собой полноценное веб-приложение интернет-магазина премиального медного оборудования и посуды ручной работы **COPPER PRO**, разработанное в строгом соответствии с макетом Figma (версия для ПК/Desktop 1440px–1920px) и всеми требованиями курсовой работы.

---

## 🛠 Технологический стек

* **Клиент (Frontend):**
  * HTML5 (семантическая верстка, методология БЭМ);
  * SCSS / CSS3 (переменные, медиа-сетка 1440px/1920px, градиенты `#5E3928` → `#E4A16F`, шрифты `Lighthaus` и `Mont`);
  * JavaScript (ES6+ асинхронный);
  * **`axios`** — для выполнения всех GET и POST запросов к серверу;
  * **`sass-embedded`** — для компиляции SCSS.

* **Сервер (Backend):**
  * **`express`** — серверный HTTP-фреймворк;
  * **`cors`** — разрешение кросс-доменных запросов с любого клиента;
  * **`dotenv`** — загрузка переменных окружения;
  * **`pg`** — официальный клиент PostgreSQL;
  * **`bcryptjs`** — безопасное хэширование паролей при регистрации и авторизации.

* **База данных:**
  * **PostgreSQL** + интерфейс **DBeaver** для администрирования.

## 🚀 Пошаговая инструкция по запуску в Visual Studio Code

### Шаг 1. Открытие проекта в VS Code
1. Откройте **Visual Studio Code**.
2. В верхнем меню выберите **File** -> **Open Folder...** (Файл -> Открыть папку).
3. Выберите папку `copper-project`.

---

### Шаг 2. Настройка базы данных в DBeaver (PostgreSQL)
1. Откройте **DBeaver** и подключитесь к вашему локальному серверу PostgreSQL (обычно порт `5432`, пользователь `postgres`).
2. Создайте новую базу данных с именем **`copper_db`** (правой кнопкой на `Databases` -> `Create New Database`).
3. В VS Code откройте файл `back/init_db.sql`, скопируйте его содержимое.
4. В DBeaver нажмите `SQL Editor` -> `New SQL Script`, вставьте содержимое файла `init_db.sql` и нажмите кнопку выполнения **Execute SQL Script (Alt + X)**.
5. Скрипт создаст 9 таблиц (`users`, `categories`, `products`, `reviews`, `benefits`, `faq`, `contact_messages`, `orders`, `order_items`) и заполнит их начальными данными.
6. В файле `back/.env` проверьте пароль от вашей БД:
   ```env
   PORT=5000
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль_в_postgres
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=copper_db
   ```
> **Примечание:** Если PostgreSQL или DBeaver еще не установлены на компьютере, бэкенд автоматически переключится в режим **In-Memory Fallback** — все GET и POST запросы, регистрация, вход и оформление заказов будут полноценно работать!

---

### Шаг 3. Запуск бэкенда (Express)
1. В VS Code откройте терминал (**Terminal** -> **New Terminal** или `Ctrl + ~`).
2. Перейдите в папку бэкенда:
   ```bash
   cd back
   ```
3. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```
4. Запустите сервер (согласно заданию командой `npm start`):
   ```bash
   npm start
   ```
   *Вы увидите сообщение:*
   ```text
   ====================================================
   🚀 Сервер COPPER PRO запущен на http://localhost:5000
   📡 API доступен по адресу: http://localhost:5000/api
   ====================================================
   ```

---

### Шаг 4. Запуск и компиляция фронтенда
1. Откройте второй терминал в VS Code (нажмите на значок `+` в правом верхнем углу панели терминала).
2. Перейдите в папку фронтенда:
   ```bash
   cd front
   ```
3. Установите зависимости фронтенда:
   ```bash
   npm install
   ```
4. Если вы хотите редактировать SCSS в реальном времени, запустите компилятор:
   ```bash
   npm run sass
   ```
   *(Файл `front/css/style.css` уже скомпилирован и готов к работе без повторной компиляции).*

5. Для запуска сайта в браузере:
   * Нажмите правой кнопкой мыши по файлу `front/index.html` в проводнике VS Code и выберите **"Open with Live Server"** (рекомендуется)
   * Либо просто дважды кликните по файлу `front/index.html` в проводнике Windows.
